# Picablur

Aplikasi ringan untuk memburamkan gambar (image blur) dengan cepat dan tanpa membebani perangkat.

## ✨ Fitur Utama

- ⚡ **Super Ringan:** Cepat dan tidak memakan banyak RAM.
- 🖼️ **Blur Cepat:** Hasil blur halus tanpa membuat aplikasi nge-lag.
- 🛠️ **Open-Source:** Bebas dipelajari dan dikembangkan bersama.

## 📥 Unduh

Dapatkan versi terbaru di halaman [Releases](https://github.com/IqwanXD/Picablur/releases/tag/v1.0).

## 🚀 Cara Menggunakan

1. Unduh file dari halaman Releases.
2. Jalankan aplikasi.
3. Pilih gambar yang ingin diburamkan.
4. Atur tingkat blur sesuai keinginan, lalu simpan hasilnya.
